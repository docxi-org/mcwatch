# CLAUDE.md — mcwatch

Сервис-агрегатор новых игр с Metacritic: сбор карточек, LLM-резюме отзывов,
похожие игры, веб-интерфейс, мониторинг. Тестовое задание для AI-инженера.

## Гейты (в порядке прохождения)

Каждый шаг в объявлении (RULES п.1.2) привязывается к одному из них.

- **G1 Сбор.** `pnpm crawl --once` кладёт 20 игр с `/game/` New Releases в SQLite
  со всеми полями карточки (название, обложка, видео, платформы + оба скора,
  разработчик, описание). Повторный запуск в тот же день берёт очередную
  страницу browse; смена даты сбрасывает состояние. Без LLM.
- **G2 Отзывы и резюме.** Для игр с отзывами сохранены отзывы критиков и
  пользователей раздельно; по каждой группе — структурированное резюме
  (нравится / не нравится); повторный обход обновляет резюме по правилу из
  архитектуры. Похожие игры считаются и возвращаются API.
- **G3 Интерфейс.** Список, карточка, фильтр по платформам, поиск по названию,
  сортировка по рейтингу, блок похожих с переходом по клику. Всё через API.
- **G4 Деплой.** `docker compose up` на VPS, HTTPS, планировщик раз в час,
  сервис доступен по ссылке. Это точка сдачи обязательной части.
- **G5 Мониторинг.** Статусы воркеров и счётчики в реальном времени (SSE),
  кнопка принудительного запуска. (Доп. часть 2)
- **G6 Летсплеи.** Для игры найден самый популярный летсплей, получен транскрипт
  (субтитры → Whisper), заключение сохранено со ссылкой, показано в карточке.
  (Доп. часть 1)

Гейт зелёный = `pnpm check` (typecheck + lint + tests) проходит **и** наблюдаемый
критерий выше выполняется. Заявленная в объявлении проверка входит в прогон.

## Зафиксированные решения (не менять без владельца)

- **Стек:** Node.js 22, TypeScript strict, ESM, pnpm. Backend — Hono.
  DB — SQLite (`better-sqlite3`) + Drizzle. Frontend — Vue 3 + Vite, статика
  отдаётся тем же процессом. Тесты — Vitest.
- **Один процесс:** HTTP + планировщик + воркеры внутри. Очередь задач — таблица
  в SQLite. Без Redis, без BullMQ, без отдельных сервисов.
- **Без браузера:** Metacritic отдаёт SSR и JSON-бэкенд. Playwright/Puppeteer
  не подключать.
- **LLM только через OpenRouter** одним ключом, через Vercel AI SDK
  (`ai` + `@openrouter/ai-sdk-provider`). Структурированный вывод —
  `generateText` + `Output.object` + zod (в AI SDK v7 `generateObject` устарел).
  Модели — константы в одном конфиге, не в коде вызовов.
- **Транскрипция:** субтитры YouTube; Whisper (OpenRouter
  `/audio/transcriptions`) — только если субтитров нет.
- **Летсплей-часть линейная**, не агентная.

## Где модель, где код

Модель делает четыре вещи: резюме отзывов, заключение по транскрипту,
**проверку «тот ли это ролик»** (решение владельца 07.09.2026 — алгоритмический
отсев дважды пропускал чужие игры, см. `docs/ARCHITECTURE.md` §4.3),
(опционально) подпись «почему похожа». Всё остальное — сбор, парсинг, ротация
страниц, выбор летсплея, похожие игры (эмбеддинги + жанры + платформы) —
детерминированный код. Предложение «пусть модель разберётся» вне этих трёх мест
— развилка для владельца, не самостоятельное решение.

## Правила кода

- Внешние вызовы (Metacritic, YouTube, OpenRouter) — через отдельные модули в
  `src/clients/`, с таймаутом, ретраем и rate-limit; из бизнес-логики напрямую
  не ходить.
- Metacritic: ≤1 запрос/с, User-Agent с названием проекта и контактом.
- Парсеры тестируются на сохранённых фикстурах (`test/fixtures/`), не на сети.
  Сетевые тесты — отдельный `pnpm test:live`, не в `pnpm check`.
- Ошибка одного элемента не роняет обход: логируется, элемент помечается
  `failed`, цикл продолжается.
- Секреты только в `.env` (есть `.env.example`). Ключей в репозитории нет.
- Пустые данные — `null`, не `0` и не выдуманный текст. Нет отзывов → нет резюме.
- Логи структурированные (pino), уровень из env.

## Команды

```
pnpm dev            # сервер + vite dev
pnpm build          # фронт + бэкенд
pnpm check          # typecheck + lint + test  ← гейт
pnpm test:live      # сетевые тесты (вручную)
pnpm crawl --once   # один цикл сбора
pnpm summarize --once  # один прогон резюме отзывов
pnpm embed --once   # эмбеддинги; --show N печатает похожие игры
pnpm db:migrate
```
