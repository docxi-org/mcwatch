# Бриф на карточку конвейера

Одно модальное окно, открывается из карточки игры. Здесь — **что** оно
показывает и как себя ведёт. Внешний вид решает исполнитель.

Замысел владельца сверх ТЗ: сервис на каждой игре шесть раз обращается к
нейросети, и результат этих обращений виден в карточке, а сам ход работы —
нет. Окно показывает ход: что ушло в модель, что она вернула и что с ответом
сделал код.

---

## 1. Зачем окно

Это тестовое задание для AI-инженера, и предмет оценки — не только каталог, но
и то, как устроен конвейер. Прятать изнанку не от кого: окно доступно всем,
кнопка стоит в карточке игры на видном месте.

Оно отвечает на четыре вопроса:

1. Сколько раз по этой игре обращались к модели, во что это обошлось?
2. Что именно ушло в модель на каждом шаге — дословно?
3. Что модель вернула?
4. Что с её ответом сделал код?

Четвёртый вопрос — не то же, что третий, и это главная тонкость окна. Судья
может ответить «совпадает, уверенность низкая», а код всё равно перейдёт к
следующему ролику. Показать только ответ модели значит соврать.

## 2. Технические рамки

Vue 3 + TypeScript, встраивается в то же приложение, что каталог и мониторинг.
Открывается из карточки игры `/game/:slug`. Данные — из двух маршрутов
раздела 6, больше ничего нет.

**Портянкой всё сразу выдавать нельзя** — прямое требование владельца. Сырьё
одного вызова доходит до 56 000 знаков; оглавление и содержимое приезжают
разными запросами, и второй делается только когда шаг раскрыли.

## 3. Что показывает окно

### 3.1 Шапка — итог по игре

Число вызовов, сорвавшихся вызовов, токенов на входе и выходе, суммарное
время, **оценка** стоимости. Слово «оценка» существенно: цена считается по
прайсу из конфига, а не приходит от провайдера, и подавать её как факт нельзя.

### 3.2 Лента этапов

Восемь этапов в порядке, в котором они происходят. Шесть с моделью, два без
неё — без них цепочка рвётся, непонятно откуда взялось сырьё и что стало с
ответом.

| Этап | Модель | Пример однострочного итога |
|---|---|---|
| Сбор карточки | нет | «117 отзывов сохранено» |
| Резюме критиков | да | «резюме сохранено · причина пересчёта: missing · в модель ушло 40 отзывов из 89» |
| Резюме игроков | да | «отзывов нет — резюмировать нечего» |
| Вектор описания | да | «вектор сохранён · 1536 чисел» |
| Похожие игры | нет | «5 из 131 прошли порог» |
| Поиск летсплеев | нет | «5 кандидатов, по убыванию просмотров» |
| Судья роликов | да | «взят» (при этом вызовов было два) |
| Заключение по летсплею | да | «заключение сохранено · ролик stK-_oN5DXg» |

У этапа есть состояние: **сделано**, **пропущено**, **сорвалось**. Пропуск —
не ошибка, и он обязан объяснять себя словами, а не пустотой.

**На одном этапе бывает несколько вызовов.** У судьи их столько, сколько
роликов он рассмотрел — до пяти. Лента показывает итог этапа, раскрытие
показывает каждый вызов отдельно.

### 3.3 Панель этапа с моделью — три раздела

**Сырьё.** Что ушло в модель, дословно, двумя частями: постоянная (инструкция
модели) и переменная (сами данные). Разделять их важно: инструкция одинакова
для всех игр, а переменная часть и есть предмет интереса.

**Работа модели.** Модель, число попыток, длительность, токены на входе и
выходе, оценка стоимости. Всё это данные из ответа, ничего не считается на
глаз.

**Решение.** Структурированный ответ модели как он пришёл — и рядом строка о
том, что сделал код. Две разные вещи, показанные раздельно.

### 3.4 Панель этапа без модели

Один раздел: что произошло, парами «ключ — значение». У сбора это источник и
счётчики отзывов, у похожих — список подобранных игр с числом близости, у
поиска летсплеев — найденные ролики с их исходами.

### 3.5 Кандидаты в летсплеи

Отдельный блок, потому что он нагляднее всего показывает работу судьи. По
каждому рассмотренному ролику: место в выдаче, название, канал, просмотры,
длительность, длина расшифровки, вердикт судьи с уверенностью и **причина
дословно**, а также итог — взят, отбракован, нет расшифровки, не
рассматривался.

Замер по нынешней базе: из 15 рассмотренных роликов **2 взяты, 8 отбракованы
как другая игра, 1 без речи, 4 не дошли до рассмотрения** — подходящий нашёлся
раньше.

## 4. Состояния, которые обязательно случатся

| Состояние | Как часто | Что делать |
|---|---|---|
| **Этап пропущен** | постоянно: у 55% игр нет отзывов, у 89% нет трейлера | Объяснить словами, почему шаг не понадобился. Это не ошибка |
| **Вызовов на этапе несколько** | у судьи — обычное дело | Итог этапа в ленте, разбивка при раскрытии |
| **Вызов делался с повторами** | замерено: до 3 попыток | Показать число попыток. Пример из базы: 3 попытки, 256 секунд — иначе непонятно, почему один шаг занял четыре минуты |
| **Вызов сорвался** | бывает | Показать ошибку. Запись о сбое так же важна, как об успехе: молчащий этап выглядит несделанным |
| **Сырьё огромное** | расшифровки от 555 до 54 572 знаков, среднее сырьё 7 400 | Нужен способ читать: прокрутка внутри своей области, свёртка, поиск по тексту на усмотрение исполнителя. Страница целиком прокручиваться не должна |
| **Постоянной части нет** | у эмбеддингов | Раздел просто отсутствует, без пустой рамки |
| **Вызов обслужил несколько игр** | эмбеддинги считаются пачками до 16 | Сказать честно: текст показан для этой игры, а токены и время — на всю пачку |
| **По игре не записано ничего** | у собранных до появления записи | Окно открывается и говорит, что этап пройден до того, как начали записывать. Не пустое окно и не ошибка |
| **Стоимость** | всегда | Подавать оценкой, а не фактом |

## 5. Как окно открывается и закрывается

Кнопка в карточке игры. Заголовок окна — название игры.

- Закрытие по Esc, по кнопке и по клику вне окна;
- фокус уходит в окно при открытии и возвращается на кнопку при закрытии;
- открытый шаг желательно отражать в адресе, чтобы ссылкой можно было
  поделиться;
- на мобильной ширине окно занимает экран целиком.

## 6. Контракт API

### `GET /api/games/:slug/pipeline`

Оглавление: этапы, метрики вызовов, кандидаты. Сырья и ответов здесь нет.

```jsonc
{
  "slug": "onimusha-way-of-the-sword",
  "title": "Onimusha: Way of the Sword",
  "totals": {
    "calls": 6, "failed": 0,
    "promptTokens": 42944, "completionTokens": 715,
    "durationMs": 279767,
    "costUsd": 0.0024276          // оценка по прайсу, не факт
  },
  "stages": [
    {
      "key": "letsplay_judge",     // один из восьми
      "title": "Судья роликов",
      "kind": "llm",               // "llm" | "code"
      "status": "done",            // "done" | "skipped" | "failed"
      "summary": "взят",           // однострочный итог для ленты
      "runs": [
        {
          "id": 4,
          "stage": "letsplay_judge",
          "subject": "L1zvS1gsAbc", // уточнение: ролик у судьи, иначе null
          "model": "z-ai/glm-4.7-flash",
          "status": "ok",           // "ok" | "failed"
          "attempts": 1,
          "durationMs": 1869,
          "promptTokens": 4935,
          "completionTokens": 72,
          "costUsd": 0.00027555,
          "batchSize": 1,           // >1 — вызов обслужил несколько игр
          "decision": "отбракован: другая игра",  // что сделал КОД
          "error": null,
          "createdAt": "2026-09-07T10:47:36.133Z"
        }
      ],
      "facts": []                   // заполнено только у этапов без модели
    }
  ],
  "candidates": [
    {
      "position": 1,
      "videoId": "L1zvS1gsAbc",
      "title": "Onimusha: Way of the Sword - Before You Buy",
      "channel": "gameranx",
      "views": 1188210,
      "durationS": 1087,
      "transcriptChars": 20203,     // null — расшифровку получить не удалось
      "matches": false,             // вердикт судьи; null — не судили
      "confidence": "low",          // "high" | "medium" | "low" | null
      "reason": "Автор называет игру 'Onimusha Warlords'…",
      "outcome": "отбракован: другая игра"
    }
  ]
}
```

Ключи этапов в порядке ленты: `crawl`, `summary_critic`, `summary_user`,
`embedding`, `similar`, `letsplay_search`, `letsplay_judge`,
`letsplay_conclusion`.

У этапов без модели `runs` пуст, а содержимое лежит в `facts` —
`[{ "key": "Отзывы критиков", "value": "89" }]`.

Неизвестный `slug` → **404** с телом `{"error":"not_found"}`.

### `GET /api/games/:slug/pipeline/runs/:id`

Сырьё и ответ одного вызова. Дёргается, только когда шаг раскрыли.

```jsonc
{
  "id": 4,
  "stage": "letsplay_judge",
  "subject": "L1zvS1gsAbc",
  "system": "Ты решаешь ровно один вопрос: играют ли в ролике…",  // постоянная часть
  "prompt": "ИГРА\nНазвание: Onimusha…\n\nРАСШИФРОВКА РЕЧИ АВТОРА (20203 знаков)\n…",
  "output": { "matches": false, "confidence": "low", "reason": "…" }
}
```

`system` бывает пустой строкой — у эмбеддингов инструкции нет.
`output` бывает `null` — вызов сорвался.

Чужой `id` по адресу другой игры → **404**: подсмотреть соседнюю карточку
через этот маршрут нельзя.

## 7. Чего не делать

- Не показывать ответ модели вместо решения кода и наоборот — это разные
  строки, и подмена одной другой искажает картину;
- не подавать оценку стоимости как факт;
- не прятать сорвавшиеся вызовы: молчащий этап неотличим от несделанного;
- не тянуть сырьё вместе с оглавлением;
- не изобретать управление конвейером: перезапуска шага, правки запроса и
  повторного вызова в API нет, окно только показывает.

## 8. Что нужно прислать

Компоненты Vue 3 + TypeScript, встроенные в то же приложение, отдельным
модальным окном из карточки игры. Данные — только из двух маршрутов выше.
