# Бриф на интерфейс mcwatch

Задание для дизайн-агента. Здесь — **что** интерфейс должен уметь и с какими
данными работает. Как это выглядит — решает исполнитель: шрифты, цвета, сетка,
композиция, анимации не задаются.

Требования-первоисточник — `docs/TASK.md`.

---

## 1. Что за сервис

Каталог новых игр с Metacritic. Раз в час сервис забирает свежие релизы,
сохраняет карточки, скачивает отзывы критиков и игроков, а нейросеть пишет по
ним короткие резюме — отдельно по критикам, отдельно по игрокам. Для каждой
игры подбираются похожие из тех, что уже есть в базе.

Аудитория — человек, выбирающий, во что поиграть: пришёл посмотреть, что
вышло нового, и стоит ли оно внимания.

Язык интерфейса — **русский**. Названия игр, разработчиков и платформ приходят
по-английски и не переводятся. Резюме отзывов приходят на русском.

## 2. Технические рамки

- **Vue 3 + Vite**, TypeScript. Собранная статика отдаётся тем же сервером,
  что и API, поэтому запросы идут на относительные пути (`/api/...`).
- Готовый бэкенд уже работает: контракт в разделе 6, менять его не нужно.
- Сторонние UI-библиотеки на усмотрение исполнителя.
- Мобильный вид обязателен: значительная часть просмотров с телефона.

## 3. Экраны

Всего два: **список игр** и **карточка игры**. Роутинг клиентский,
адрес карточки — `/game/:slug`.

### 3.1 Список игр

Главный экран. Показывает игры из базы и даёт их отобрать.

**По каждой игре в списке доступно:** обложка, название, дата выхода,
разработчик, жанры, перечень платформ, лучший метаскор и лучшая оценка
игроков.

**Управление списком — четыре независимых средства, работают совместно:**

| Средство | Поведение |
|---|---|
| Фильтр по платформе | Одна платформа за раз либо «все». Список платформ приходит с сервера вместе с числом игр на каждой — платформ, которых нет в базе, в фильтре быть не должно |
| Поиск по названию | Подстрока, регистр не важен. Ищется только по названию игры |
| Сортировка | Четыре варианта: по метаскору, по оценке игроков, по дате выхода (по умолчанию), по названию |
| Постраничность | Сервер отдаёт страницу и общее число подходящих игр. Листание или подгрузка — на усмотрение исполнителя |

Фильтр, поиск и сортировка должны переживать перезагрузку страницы и быть
пригодными для ссылки — то есть жить в адресной строке.

**Клик по игре открывает её карточку.**

### 3.2 Карточка игры

**Обязательно показывает** (это прямое требование ТЗ):

- название, обложку, описание;
- разработчика и издателя;
- дату выхода и возрастной рейтинг ESRB;
- жанры;
- **таблицу платформ**: по каждой платформе свой метаскор и своя оценка
  игроков — это разные числа, и объединять их нельзя;
- ссылку на видео-трейлер;
- **два резюме отзывов**: по критикам и по игрокам, каждое состоит из списка
  «что нравится», списка «что не нравится» и общего вывода;
- **блок похожих игр**; клик по любой открывает её карточку.

## 4. Две шкалы оценок — не перепутать

Это главная предметная тонкость.

- **Метаскор** — оценка критиков, шкала **0–100**.
- **Оценка игроков** — шкала **0–10**, дробная (например 8.7).

Показывать их надо так, чтобы их нельзя было спутать: 85 и 8.5 — это оценки
разного происхождения по разным шкалам, а не «85» и «8.5 из 100».

У Metacritic принята цветовая градация, и её стоит воспроизвести — читатели
каталогов игр её узнают:

| Метаскор | Оценка игроков | Смысл |
|---|---|---|
| 75–100 | 7.5–10 | Хорошо |
| 50–74 | 5.0–7.4 | Средне |
| 0–49 | 0–4.9 | Плохо |

Конкретные цвета — на усмотрение исполнителя.

## 5. Состояния, которые обязательно случатся

Данные приходят с чужого сайта, и они неполные. **Это норма, а не сбой.**
Интерфейс должен выглядеть достойно в каждом из этих случаев:

Доли ниже — замер по реальной базе из 44 игр, а не оценка на глаз.

| Состояние | Как часто | Что делать |
|---|---|---|
| **Нет трейлера** | **89% игр** | Блок видео просто отсутствует |
| **Нет ESRB** | **70%** | Поле отсутствует |
| **Нет метаскора у платформы** | **62% строк платформ.** У платформы бывает 2–3 рецензии, и Metacritic не выводит оценку | «Нет оценки», не рисовать 0 |
| **Нет оценки игроков у платформы** | **56% строк** | То же |
| **Нет отзывов, а значит и резюме** | **55% игр** | «Отзывов пока нет» вместо блока резюме |
| **Есть резюме только одного вида** | 7 игр из 20 с резюме | По критикам может быть, а по игрокам нет — и наоборот. Блоки независимы |
| **Нет описания** | **30%** | Не оставлять пустое место молча |
| **Нет обложки** | **11%** | Нужна заглушка. Это самый заметный случай: в списке карточка без картинки не должна разваливать сетку |
| **Похожих не нашлось** | Регулярно, особенно у спортивных симуляторов и одиночных жанров | Пустой блок с пояснением. Показывать случайные игры вместо похожих нельзя |
| **Поиск ничего не нашёл** | — | Внятное сообщение |
| **База пуста** | При первом запуске сервиса | Экран должен что-то говорить, а не выглядеть сломанным |
| **Игра помечена `failed`** | Редко, но бывает | Последний обход не удался, данные могут быть неполными. Скрывать её не надо |

Ноль и «нет данных» — **разные вещи**. Оценка `null` означает «никто не
оценил»; `0` означает, что оценили на ноль. Числа `0` в полях оценок
встречаются и они настоящие.

Отдельно: обложки отдаются в оригинальном размере, часто по 300–500 КБ, и
приходят с чужого домена — уменьшить их на сервере нельзя. Список из двух
десятков игр не должен из-за этого открываться минуту, и битая ссылка на
картинку не должна ломать вёрстку.

## 6. Контракт API

Три маршрута. Все отвечают JSON в UTF-8.

### `GET /api/games`

Параметры запроса, все необязательные:

| Параметр | Значения | По умолчанию |
|---|---|---|
| `platform` | точное имя платформы из `/api/platforms` | все |
| `q` | подстрока названия | — |
| `sort` | `metascore` \| `userscore` \| `date` \| `title` | `date` |
| `page` | целое ≥ 1 | 1 |
| `pageSize` | целое 1–100 | 24 |

```jsonc
{
  "items": [
    {
      "slug": "onimusha-way-of-the-sword",
      "title": "Onimusha: Way of the Sword",
      "coverUrl": "https://www.metacritic.com/a/img/catalog/...jpg",  // может быть null
      "releaseDate": "2026-09-04",        // может быть null
      "developer": "Capcom",              // может быть null
      "genres": ["Action Adventure"],     // может быть []
      "platforms": ["PC", "PlayStation 5"],
      "bestMetascore": 89,                // 0–100, может быть null
      "bestUserscore": 9.3,               // 0–10, может быть null
      "status": "ok"                      // "ok" | "failed"
    }
  ],
  "total": 44,      // всего подходящих под фильтр, не размер страницы
  "page": 1,
  "pageSize": 24
}
```

`bestMetascore` и `bestUserscore` — лучшие значения среди платформ игры;
нужны для сортировки и для показа в списке одним числом.

### `GET /api/games/:slug`

```jsonc
{
  "slug": "onimusha-way-of-the-sword",
  "title": "Onimusha: Way of the Sword",
  "coverUrl": "https://...jpg",
  "videoUrl": "https://cdn.jwplayer.com/players/Eibtv31Y.html",  // null — трейлера нет
  "developer": "Capcom",
  "publisher": "Capcom",
  "description": "Fight through bloodstained battlefields…",     // часто null
  "genres": ["Action Adventure"],
  "releaseDate": "2026-09-04",
  "esrb": "M",                                                   // часто null
  "status": "ok",
  "platforms": [
    {
      "platform": "PlayStation 5",
      "metascore": 85,        // 0–100, может быть null
      "userscore": 8.8,       // 0–10,  может быть null
      "criticCount": 93,      // сколько рецензий учтено, может быть null
      "userCount": 177
    }
  ],
  "summaries": {
    "critic": {
      "likes": ["Возвращение легендарной серии", "Блестящая боевая система"],
      "dislikes": ["Излишний открытый мир", "Повторяющиеся боссы"],
      "summary": "Onimusha — триумфальное возвращение серии…",
      "reviewCount": 89,                      // по скольким отзывам сделано
      "model": "z-ai/glm-4.7-flash",
      "createdAt": "2026-09-07T12:00:00.000Z"
    },
    "user": null                              // отзывов игроков нет
  },
  "reviewCounts": { "critic": 89, "user": 28 },
  "similar": [
    {
      "slug": "resonance-a-plague-tale-legacy",
      "title": "Resonance: A Plague Tale Legacy",
      "coverUrl": "https://...jpg",
      "bestMetascore": 84,
      "score": 0.698        // близость; служебное, показывать не нужно
    }
  ]
}
```

Списки `likes` и `dislikes` — до пяти пунктов, каждый до 120 знаков.
Блок `similar` — до пяти игр, может быть пустым.

Неизвестный `slug` → **404** с телом `{"error":"not_found"}`.

### `GET /api/platforms`

```jsonc
[
  { "platform": "PC", "gameCount": 41 },
  { "platform": "PlayStation 5", "gameCount": 17 }
]
```

Только те платформы, что есть в базе. Годится для фильтра как есть.

### Ошибки

| Код | Тело | Когда |
|---|---|---|
| 400 | `{"error":"bad_request","details":[{"field":"sort","message":"…"}]}` | негодные параметры запроса |
| 404 | `{"error":"not_found"}` | нет такой игры или маршрута |
| 500 | `{"error":"internal_error"}` | сбой на сервере |

## 7. Чего в этой версии нет

Не проектировать и не рисовать:

- авторизацию, личные кабинеты, избранное, оценки от посетителей;
- комментарии и любое пользовательское содержимое;
- полные тексты отзывов — показываются только резюме;
- фильтры по жанру, году, разработчику;
- тёмную/светлую тему по выбору пользователя, если исполнитель не сочтёт это
  уместным сам.

Экран мониторинга работы сервиса (статусы воркеров, счётчики, кнопка
принудительного запуска) — **отдельная задача**, в этот бриф не входит.

## 8. Что нужно прислать

Исходники Vue 3 + TypeScript: компоненты, роутинг, слой запросов к API,
стили. Сборка через Vite. Данные брать только из трёх маршрутов выше —
выдуманных полей быть не должно.
